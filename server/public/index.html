Informasi proyek dan pengembang SuperTinyServer

SuperTinyServer

v0.1.0

SuperTinyServer (STS) adalah mini server berbasis Android dan Termux yang dirancang untuk mengubah perangkat Android tablet/smartphone menjadi server portable ringan, hemat daya, dan mudah dinavigasi secara lokal.

👨‍💻 Pengembang & Kontributor

Dikembangkan sebagai solusi praktis untuk memantau performa tablet, melihat IP server secara otomatis, dan berbagi file antar perangkat lokal (File Drop) melalui antarmuka web modern & responsif.

⚙️ Teknologi Utama

Android Termux Node.js Express.js OpenSSH HTML5 / CSS3 / JS
